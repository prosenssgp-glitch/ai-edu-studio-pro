# Quiz Video Maker

Mobile-first starter app for creating quiz previews and experimental WebM exports.

## Run
Open `index.html` in a modern browser, or enable GitHub Pages for the `quiz-video-maker` folder by copying `index.html` to the repository root (GitHub Pages serves the repository root or `/docs` by default).

## Notes
- Built-in example questions work offline after the page is loaded.
- AI question generation is not connected yet; it requires a secure server/API endpoint. Never put an AI secret key in public browser code.
- Browser export, especially long exports, depends on the device and browser and must be tested. Current export uses WebM where supported, not guaranteed MP4.
- Use images/audio only when you have permission or a suitable commercial license.
